# QasidRelay 0.1.8-rc1 — QA candidate

Status: **SOURCE AND CI CANDIDATE ONLY**. Do not describe as a validated
production release or publish a stable/tagged APK until real-device acceptance
is recorded.

## Operator improvements

The compact overview now hides advanced status rows by default on a small
screen and keeps the primary SMS controls above infrequently edited setup.
The emulator CI saves a 320x640 operator screenshot for review. Real-device
font scaling and accessibility checks remain release gates.


- Clear health overview, relative timestamps, next-action controls, and safe
  gateway diagnosis with redacted copyable support diagnostics.
- Separate 20-event privacy-preserving activity list, useful failure labels,
  and confirmed clearing that leaves pending reports/deduplication untouched.
- Safer server setup, key-change guards, confirmed forget-server, and manual
  version/release and help links.
- Android battery guidance, opt-in system device-credential lock, safe worker
  status notification, and passive guided phone smoke checklist.
- Optional informational gateway destination-policy label, backward compatible
  with an unmodified server.

## Safety and reliability changes

- Foreground worker now requests `START_NOT_STICKY`; it must not silently
  resume SMS polling after reboot, replacement or process death.
- Redacted coarse exception categories instead of raw network exception logs.
- Refuse server/key change while messaging remains enabled, a submitted
  Android SMS is awaiting callbacks, or reports are queued.
- A new gateway identity resets the UI smoke checklist, local history,
  deduplication ledger and gateway health state after it is safe to switch.
- All SMS jobs continue to require authorized SIM/carrier use, explicit
  operator start, HTTPS/HMAC gateway verification, and the server's own
  destination allowlist and rate limits.

## Physical-device blockers before publication

- [ ] Sign and install this candidate on an authorized physical Android SIM
      phone; preserve signing continuity from v0.1.7.
- [ ] Run complete end-to-end OTP/test-message smoke (one send attempt, one
      server acknowledgement), send-failure, no-network and retry checks.
- [ ] Verify Android Keystore, device credential lock, safe server switching,
      foreground notification, process-death/manual restart and battery behavior.
- [ ] Verify real-device dual-SIM routing assumptions. **Selection is not yet
      implemented**; the system default remains in use.
- [ ] Inspect recent activity, screenshots, clipboard diagnostics and large-font
      layout for privacy, correctness and accessibility.
- [ ] Test the optional gateway policy with an explicitly compatible test server;
      older server contracts must still operate.
- [ ] Confirm emulator and JUnit jobs pass at the final candidate head.
- [ ] After successful evidence, decide whether to create a GitHub
      `v0.1.8-rc1` prerelease. No stable release is implied here.

## Deferred / intentionally excluded

- Dual-SIM subscription selection and multi-profile migration (device-specific
  safety and migration testing required).
- Automatic battery exemption, hidden sending, remote control of the phone,
  inbox/SMS reading, bulk campaigns, SMS delivery receipt claims.
- Automatic in-app APK download/install, hosted reference gateway and SDK
  implementations. These are separate milestones.
